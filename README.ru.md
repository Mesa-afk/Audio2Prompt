## Проблема

Whisper — превосходная модель распознавания речи, но её *сырой вывод* плохо подходит для языковых моделей:

- **Текст рваный.** Whisper выдаёт сотни коротких сегментов по 2–6 секунд. Результат читается как сломанный сценарий, а не как транскрипция, и каждый лишний перенос строки расходует контекст.
- **Впустую тратится контекстное окно.** Таймкоды вроде `[00:42:13 --> 00:42:19]` — чистый шум для ChatGPT или Claude. На двухчасовой записи они легко съедают тысячи токенов ещё до того, как модель увидит первое полезное предложение.
- **Установка — боль.** Большинству обёрток над Whisper нужен системный FFmpeg, CUDA Toolkit и «хирургия» с Python-пакетами. Для человека, который просто хочет расшифровать свой подкаст, это непреодолимый барьер.
- **Длинные файлы всё ломают.** Наивные обёртки загружают 200-мегабайтный файл, замораживают интерфейс, не показывают прогресс и не умеют отменяться. Если что-то пошло не так на втором часу — результат потерян.

Voice2LLM решает все эти проблемы: аудио декодируется сборкой PyAV, встроенной в `faster-whisper` (системный FFmpeg не нужен), тишина отсекается через Silero VAD, фрагменты склеиваются в читаемые абзацы, а результат в реальном времени появляется в тёмном отзывчивом десктопном приложении.

## Возможности

- **100% локально и приватно.** Аудио не покидает ваш компьютер. Ни API-ключей, ни аккаунтов, ни телеметрии.
- **FFmpeg не требуется.** MP3, WAV, M4A, FLAC, OGG и другие форматы декодируются встроенными библиотеками PyAV — и при запуске из исходников, и в собранном бинарнике.
- **Фильтрация тишины Silero VAD.** Паузы пропускаются (`min_silence_duration_ms=500`), что убирает галлюцинации и ускоряет обработку длинных записей.
- **Готовый для LLM текст.** Таймкоды удаляются, фразы склеиваются в абзацы, а в начало при необходимости добавляется системный промпт — текст можно сразу вставлять в ChatGPT или Claude.
- **Два режима вывода.**
  - **LLM Ready** — аккуратные абзацы без таймкодов и опциональный системный промпт:
    > Ниже представлена транскрибация аудиозаписи. Проанализируй текст, выдели ключевые тезисы, инсайты и список задач (Action Items):
  - **С таймкодами** — `[HH:MM:SS -> HH:MM:SS] Текст`, удобно для субтитров и цитирования.
- **Точность в приоритете.** Доступна полная модель `large-v3` наряду с быстрой `large-v3-turbo`, есть отдельный **точный режим** (beam 10, `float32` на CPU и промпт с пунктуацией), а поле **«Контекст»** передаёт имена, бренды и термины в Whisper как hotwords.
- **Автоматическое ускорение на GPU.** При наличии совместимой видеокарты выбирается CUDA + `float16`, иначе приложение безопасно переходит на CPU (`int8`, а в точном режиме — `float32`) и даже повторяет обработку на CPU, если CUDA падает посреди работы. Строка статуса всегда показывает фактически используемые устройство и тип вычислений.
- **Живая обратная связь.** Потоковые сегменты, процент выполнения, прошедшее и оставшееся время, счётчик слов и оценка токенов (`слова × 1.33`).
- **Отмена и потокобезопасность.** Распознавание идёт в отдельном `threading.Thread`; GUI обновляется только через `queue.Queue`, а `threading.Event` аккуратно останавливает работу, сохраняя уже готовый текст.
- **Современный тёмный интерфейс.** `customtkinter` с фоном `#0B0B0D`, панелями `#16161A`, акцентами `#A855F7`, автопрокруткой, копированием в один клик и экспортом в `.txt` / `.md`. Интерфейс приложения — на русском языке.
- **Сборка одной папкой.** Упаковка `--onedir` означает, что модели мгновенно загружаются из папки `models/` рядом с исполняемым файлом, без распаковки во временный каталог.

### Windows — скачать и запустить

1. Откройте **[последний релиз](https://github.com/Mesa-afk/Voice2LLM/releases/latest)**.
2. Скачайте **`Voice2LLM-windows-x64.zip`**.
3. Распакуйте архив в любое место (например, `C:\Tools\Voice2LLM`).
4. Запустите **`Voice2LLM.exe`**.
5. Выберите аудиофайл и модель, нажмите **«Начать транскрибацию»**.

> **Первый запуск:** выбранная модель Whisper скачивается с Hugging Face в папку `models/` рядом с исполняемым файлом. `base` занимает несколько сотен мегабайт, `large-v3-turbo` — около 1,6 ГБ, `large-v3` — около 3,1 ГБ. Дальнейшие запуски мгновенные и полностью работают офлайн.

> **Для максимальной точности** выберите `large-v3`, оставьте **«Точный режим»** включённым и добавьте имена и термины в **«Контекст»** — см. [Как повысить точность](#как-повысить-точность). Это медленнее, особенно без CUDA GPU.

> **Windows SmartScreen:** бинарник не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер». Выберите *Подробнее → Выполнить в любом случае*.

### Linux — сборка и запуск из исходников

Готового Linux-архива **нет**: бинарники PyInstaller привязаны к платформе, и собрать Linux-версию на Windows нельзя. Собрать её нужно самостоятельно на Linux — это занимает несколько минут.

#### 1. Установите системные пакеты

`customtkinter` нужен Tk, а `pyperclip` — утилита буфера обмена:

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install -y python3 python3-venv python3-pip python3-tk xclip

# Fedora
sudo dnf install -y python3 python3-tkinter xclip

# Arch
sudo pacman -S --needed python tk xclip
```

На Wayland установите `wl-clipboard` (`sudo apt install wl-clipboard` в Debian/Ubuntu) вместо `xclip`.

#### 2. Клонируйте репозиторий и установите зависимости

```bash
git clone https://github.com/Mesa-afk/Voice2LLM.git
cd Voice2LLM

python3 -m venv venv
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt
```

#### 3. Запустите приложение

```bash
python main.py
```

#### 4. Соберите переносимую Linux-сборку (опционально)

```bash
python build.py --zip
```

Результат — самодостаточная папка `dist/Voice2LLM/` с лаунчером `Voice2LLM` и архив `dist/Voice2LLM-linux-x64.zip` (на ARM суффикс будет `linux-arm64`). Собирайте на самом старом дистрибутиве, который планируете поддерживать: бинарник PyInstaller линкуется с glibc сборочной машины и не запустится на более старых системах.

> **GPU (опционально):** ускорение CUDA работает с NVIDIA GPU и совместимым runtime CUDA/cuDNN. Без него приложение автоматически использует CPU `int8` на всех доступных ядрах.

### macOS — сборка и запуск из исходников

Готового macOS-архива пока **нет**. Приложение работает нативно на Intel и Apple Silicon, но **у CTranslate2 на macOS нет бэкенда Metal/MPS**, поэтому распознавание идёт только на CPU — для длинных записей выбирайте `small` или `medium`.

#### 1. Установите Python 3.10+ с Tk

Установщик с python.org включает Tk. В Homebrew установите подходящую формулу Tk явно (пример для Python 3.12):

```bash
brew install python@3.12 python-tk@3.12
```

#### 2. Клонируйте репозиторий и установите зависимости

```bash
git clone https://github.com/Mesa-afk/Voice2LLM.git
cd Voice2LLM

python3 -m venv venv
source venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python main.py
```

#### 3. Соберите локальную сборку одной папкой (опционально)

```bash
python build.py --console
```

В режиме по умолчанию (`--noconsole`) PyInstaller создаёт бандл `Voice2LLM.app`, а `build.py` проверяет обычную папочную сборку; поэтому `--console` создаёт сборку в `dist/Voice2LLM/`. Для распространения `.app` желательно подписать и нотаризовать его; Gatekeeper предупреждает о неподписанных сборках.

## Выбор модели

| Модель | Параметры | Диск | Качество | Рекомендуемое железо |
| --- | --- | --- | --- | --- |
| `base` | 74 M | ~145 МБ | Черновое качество, хорошо для чёткой речи | Любой CPU, очень быстро |
| `small` | 244 M | ~485 МБ | Хороший баланс (по умолчанию) | Современный CPU, на GPU ~10× быстрее |
| `medium` | 769 M | ~1,5 ГБ | Высокое качество, уверенно справляется с акцентами | Желательна GPU (4 ГБ+ VRAM) |
| `large-v3-turbo` | 809 M | ~1,6 ГБ | Отличное качество на высокой скорости | Настоятельно рекомендуется GPU (6 ГБ+ VRAM) |
| `large-v3` | 1,55 B | ~3,1 ГБ | **Максимальная точность**, лучшая русская пунктуация и редкие слова | NVIDIA GPU (10 ГБ+ VRAM); CPU работает, но медленно |

Двухчасовой подкаст на средней видеокарте с `large-v3-turbo` обычно обрабатывается за несколько минут; та же задача на CPU с `small` заметно медленнее, но тоже выполнима.

**Примечания по платформам.** Windows и Linux могут использовать NVIDIA GPU через CUDA (`float16`); без подходящей GPU приложение автоматически выбирает CPU (`int8`, а в точном режиме — `float32`). На macOS доступен только CPU, так как CTranslate2 не поддерживает Metal/MPS, поэтому `large-v3-turbo` на Mac заметно медленнее — обычно лучше выбрать `small` или `medium`.

## Как повысить точность

Качество Whisper зависит в первую очередь от модели и самого аудио, а не от настроек интерфейса. Если в тексте встречаются ослышки, пропущенные фразы или сломанная пунктуация, пройдите по списку по порядку:

1. **Выберите `large-v3`.** Это самая точная модель Whisper для русского и большинства других языков. `base` и `small` подходят для черновика, но не для финальной транскрибации.
2. **Оставьте «Точный режим» включённым.** Он поднимает `beam_size` с 5 до 10, использует `float32` вместо `int8` на CPU и добавляет промпт с пунктуацией. На CPU распознавание станет заметно медленнее (часто в 2–4 раза) — это осознанный обмен скорости на качество.
3. **Опишите запись в поле «Контекст».** Имена, компании, названия продуктов, аббревиатуры и термины передаются в Whisper как hotwords в каждом 30-секундном окне. Например: `Иван Петров, Kubernetes, Voice2LLM, выручка, CAC, LTV`.
4. **Указывайте язык явно.** `ru` или `en` надёжнее автоопределения, особенно если в записи есть музыка, тишина или несколько собеседников. Автоопределение анализирует первые три 30-секундных окна, и позже язык нельзя исправить, поэтому явный выбор всё равно надёжнее.
5. **Берите максимально качественный исходник.** Перекодированный в 64 кбит/с файл теряет согласные, которые не восстановит никакая модель. Лучше оригинальный WAV/M4A/MP3, без фоновой музыки и агрессивного шумоподавления.
6. **Проверьте, какое устройство работает.** Строка статуса показывает `GPU · CUDA · float16` или `CPU · float32`. GPU не меняет саму модель, но делает `large-v3` достаточно быстрой; если после сообщения «GPU-ускорение недоступно» приложение работает на CPU, значит runtime CUDA/cuDNN установлен не полностью.

Точный режим действует и в формате **«С таймкодами»**, поэтому оба варианта вывода используют одни и те же настройки декодера.

## Как это работает

```
audio.mp3 ──► декодер PyAV ──► 16 кГц моно PCM ──► Silero VAD ──► CTranslate2
                                                                    │
                                             потоковые сегменты ◄────┘
                                                   │
                                    TranscriptPostProcessor
                                  (абзацы / таймкоды / промпт)
                                                   │
                                        queue.Queue ──► интерфейс customtkinter
```

- **Декодирование:** PyAV (поставляется вместе с `faster-whisper`) демультиплексирует и пересэмплирует MP3/WAV/M4A без внешних инструментов.
- **VAD:** Silero VAD отбрасывает тишину, чтобы модель не галлюцинировала на паузах.
- **Инференс:** CTranslate2 запускает модель Whisper с `beam_size=5`, а в точном режиме — с `10`; там же CPU переключается на `float32` и добавляется промпт с пунктуацией. Воркер берёт длительность аудио из заголовка контейнера, поэтому прогресс и ETA доступны ещё до прихода первого сегмента.
- **Словарь:** имена и термины из поля «Контекст» передаются как hotwords Whisper, смещая каждое окно декодирования к ожидаемому написанию.
- **Постобработка:** абзац закрывается, когда пауза между сегментами превышает **2,0 секунды**, после **6–8 предложений** или когда абзац разрастается сверх **700 символов**. Пунктуация в конце предложений нормализуется, а первая буква каждого абзаца делается заглавной, чтобы получился связный текст.

## Для разработчиков

### Требования

- Python **3.10+**
- Рабочая установка Tk (идёт в комплекте с официальными установщиками Windows и macOS; в Linux установите `python3-tk`)
- Опционально: NVIDIA GPU с CUDA для аппаратного ускорения (приложение работает на CPU «из коробки»)

### Запуск из исходников

```bash
git clone https://github.com/Mesa-afk/Voice2LLM.git
cd Voice2LLM

python -m venv venv
# Windows (PowerShell)
.\venv\Scripts\Activate.ps1
# macOS / Linux
source venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt

python main.py
```

Веса моделей кэшируются в папке `models/` рядом с `main.py` (исключена из git). Если эта папка недоступна для записи, приложение использует `~/.cache/voice2llm/models`.

### Сборка автономного бинарника

```bash
python build.py           # dist/Voice2LLM/ (одна папка)
python build.py --zip     # дополнительно создаёт архив для платформы
python build.py --console # оставить консоль для отладки
```

Скрипт сборки:

- проверяет версию Python и установленные зависимости;
- очищает прежние артефакты `build/`, `dist/Voice2LLM` и `Voice2LLM.spec`;
- настраивает `--noconsole`, `--onedir`, `--noupx` и ресурс `VERSIONINFO` для Windows;
- включает в сборку `customtkinter`, `faster_whisper`, `ctranslate2`, `tokenizers`, `onnxruntime`, `av` и `huggingface_hub` через `--collect-all`;
- исключает тяжёлые неиспользуемые пакеты вроде `torch` и `pandas`;
- проверяет наличие исполняемого файла и печатает итоговый размер.

> **Кросс-платформенное примечание.** PyInstaller не умеет кросс-компиляцию, поэтому собирайте на той ОС, для которой нужен бинарник. В Linux получается `dist/Voice2LLM/Voice2LLM`; в Windows — `dist/Voice2LLM/Voice2LLM.exe`; в macOS оконный режим по умолчанию создаёт бандл `Voice2LLM.app`, поэтому для обычной папочной сборки используйте `python build.py --console`. GitHub Actions workflow сейчас собирает только Windows.

Положите `assets/icon.ico` (Windows), `assets/icon.icns` (macOS) или `assets/icon.png` (Linux) в репозиторий, чтобы задать иконку бинарника.

```bash
git push origin v1.0.0
```

Workflow запускается только по тегам версий (`v*`), выполняется на `windows-latest` и всегда публикует Windows-архив в GitHub Release; именно разрешение `contents: write` позволяет прикрепить файл к релизу. Linux- и macOS-бинарники он не собирает — PyInstaller не умеет кросс-компиляцию, поэтому их нужно собирать на соответствующей ОС (см. раздел «Быстрый старт»).

## Решение проблем

| Симптом | Что делать |
| --- | --- |
| «GPU-ускорение недоступно… перезапуск на CPU» | Не хватает DLL для CUDA/cuDNN или драйвер дал сбой. Приложение уже перезапустило распознавание на CPU и сбросило таймер; установите NVIDIA runtime, если нужна скорость GPU. |
| Первая транскрибация очень медленная | Скачивается модель. Следите за строкой статуса; последующие запуски грузятся из `models/` мгновенно. |
| «Не удалось определить длительность аудиофайла» | Файл повреждён или не содержит аудиопотока. Переэкспортируйте его в MP3/WAV/M4A. |
| Предупреждение SmartScreen или антивируса | Ожидаемо для неподписанного бинарника PyInstaller. Проверьте контрольную сумму релиза или соберите приложение из исходников. |
| Кнопка копирования не работает в Linux | Установите бэкенд буфера обмена для `pyperclip` (`xclip`, `xsel` или `wl-clipboard`). |
| `ModuleNotFoundError: No module named 'tkinter'` | Установите Tk: `sudo apt install python3-tk` (Debian/Ubuntu) или `sudo dnf install python3-tkinter` (Fedora). |
| `ModuleNotFoundError: customtkinter` | Активируйте виртуальное окружение и выполните `pip install -r requirements.txt`. |

## Приватность

Voice2LLM выполняет все операции локально: никаких сетевых вызовов, кроме однократного скачивания модели с Hugging Face, никакой аналитики и отчётов о сбоях. Аудио и транскрипции остаются на вашем диске.
